🆘 New to this? What is Pandas, and how do I "open" a file with it?

Pandas is a Python library (a ready-made toolbox) for working with tables of data, like an Excel sheet. A table loaded into Pandas is called a DataFrame. The line pd.read_csv("house_data.csv") means: open this CSV file and turn it into a DataFrame called data.

5Evaluate

A model that cannot be measured cannot be trusted. Common metrics: MAE, MSE, RMSE, R².

from sklearn.metrics import mean_absolute_error
mae = mean_absolute_error(y_test, predictions)
print(mae)
🆘 How do I evaluate my model? (step by step)

Evaluating means checking how wrong your model is on houses it has never seen before. A model that only works on the houses it studied is not useful.

  1. Split the data: 80% to learn from (train), 20% to test with, using train_test_split.
  2. Train on the 80%: model.fit(X_train, y_train).
  3. Predict the 20%: predictions = model.predict(X_test).
  4. Compare with the real prices: mean_absolute_error(y_test, predictions). Lower is better, and it is in the same unit as price (Lakh).

6Build the Streamlit app

import streamlit as st
area = st.number_input("Area")
bedrooms = st.number_input("Bedrooms")
bathrooms = st.number_input("Bathrooms")
age = st.number_input("Age")

if st.button("Predict"):
    result = model.predict([[area, bedrooms, bathrooms, age]])
    st.success(f"Predicted Price: {result[0]}")
🆘 How do I build and run the app? (step by step)

Streamlit turns a Python file into a web page, with no HTML needed.

  1. Create a folder house-price-prediction on your computer and put house_data.csv inside.
  2. Install the tools: pip install streamlit pandas scikit-learn
  3. Create a file app.py. Put your loading and training code at the top (so the variable model exists), then the app code from above below it.
  4. Open a terminal inside the folder and run streamlit run app.py. Your browser opens the app.
  5. Type some values and press Predict.

Docs: Get started with Streamlit

Run it with streamlit run app.py. Deploy free on Hugging Face Spaces or Render.
